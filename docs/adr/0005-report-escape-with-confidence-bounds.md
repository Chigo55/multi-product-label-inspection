# Escape는 관측값이 아니라 신뢰구간과 함께 보고한다

Escape 관측 비율만 적으면 표본이 작을 때 결론이 과장된다. `CRITICAL` 불량 12건 중 0건 escape는
"Recall 100%"가 아니라 **상한 약 22%** 를 뜻한다. 그래서 모든 비율 지표는 분자/분모와 함께
**Clopper-Pearson(exact) 95% 신뢰구간**을 병기하고, escape가 0건이면 상한(`≈ 3/n`)을 명시한다.

랜덤성이 있는 실험(few-shot 샘플링 등)은 최소 3 seed로 돌려 평균 ± 표준편차로 보고한다.

## Consequences

"Critical Escape 0"을 주장하려면 필요한 표본 수가 먼저 정해진다. 목표 상한이 정해지면 데이터셋
크기 요구사항이 거기서 역산되므로, 이 규칙은 보고 형식이 아니라 데이터 수집 계획의 제약이다.
